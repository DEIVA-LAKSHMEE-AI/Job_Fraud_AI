## 5 EASY STEPS

### 1️⃣ GET OPENAI KEY (5 min)
```
👉 Go to: https://platform.openai.com/account/api-keys
📝 Click: "Create new secret key"
💾 Copy: The key (starts with sk_)
✅ Save: In notepad for Step 3
```

**If first time:**
```
1. https://platform.openai.com → Sign up
2. Verify email
3. https://platform.openai.com/account/billing/overview
4. "Set up paid account" + add credit card
5. Go back to api-keys link above
```

---

### 2️⃣ CREATE GITHUB ACCOUNT (2 min)
```
👉 Go to: https://github.com/signup
📝 Sign up with email
✅ Verify email
```

---

### 3️⃣ CREATE GITHUB REPO (3 min)
```
👉 Go to: https://github.com/new
📝 Name: jobshield-ai
📝 Description: AI job offer fraud detector
☑️ Select: Public
✅ Click: "Create repository"
```

---

### 4️⃣ UPLOAD YOUR FILES (5 min)
```
On your new GitHub repo page:
👉 Click: "uploading an existing file"
📁 Drag & drop: ALL files from jobshield-ai folder
✅ Click: "Commit changes"
```

---

### 5️⃣ DEPLOY TO VERCEL (10 min)
```
👉 Go to: https://vercel.com
☑️ Click: "Sign Up"
☑️ Click: "Continue with GitHub"
☑️ Authorize Vercel
✅ Click: "Add New" → "Project"
```

**Then:**
```
👉 Click: "Import Git Repository"
📝 Paste: https://github.com/YOUR_USERNAME/jobshield-ai
✅ Click: "Import"
```

**Critical Step - Add API Key:**
```
👉 Look for: "Environment Variables"
📝 Name: OPENAI_API_KEY
📝 Value: Paste your key from Step 1
✅ Click: "Add"
✅ Click: BIG BLUE "Deploy" button
```

**Wait 3-5 minutes...**
```
✅ When done: See "Congratulations!"
🎉 Your URL: https://jobshield-ai-xxx.vercel.app
```
